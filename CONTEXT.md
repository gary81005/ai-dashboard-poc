# CONTEXT：個人化儀表板 POC 名詞表

使用者在瀏覽器上傳**制式化 Excel**，把欄位拖進圖表的**槽位**，自己組出一個可以拖動、縮放的**儀表板**。沒有自己的後端：瀏覽器直接連 Supabase，資料集、資料列、原始檔和儀表板設定都存在 Supabase，每位使用者只看得到自己的資料（見 [ADR 0007](docs/adr/0007-supabase-storage.md)）。

這份文件定義專案裡的共用名詞。寫程式、寫文件、開 issue 時都用這裡的詞，程式碼裡則用「程式碼命名」欄的英文名稱。決策的理由記在 [`docs/adr/`](docs/adr/)。

## 資料端

| 名詞       | 程式碼命名                       | 定義                                                                                                                                                                                                   |
| ---------- | -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 活頁簿     | `Workbook`                       | 使用者上傳的 `.xlsx` 檔案本身。                                                                                                                                                                        |
| 結構規範   | —                                | 可以上傳的 Excel 必須遵守的規則：第 1 列是標頭、第 2 列起是資料、沒有合併儲存格、沒有小計列。原文寫在範例檔的「使用說明」工作表。                                                                      |
| 工作表     | `sheetName`                      | Excel 裡的實體分頁。**只用來指 Excel 的分頁**，系統內「可以畫圖的一張表」請叫「資料表」。                                                                                                              |
| 資料集     | `Dataset` / `datasetId`          | 一份活頁簿上傳、解析之後的結果。中繼資料（資料表、欄位、角色）存在 Supabase 的 `datasets`，資料列存在 `dataset_rows`。每上傳一次就產生一個新的資料集。                                                 |
| 資料列     | `Row` / `dataset_rows`           | 資料表裡的一列資料，是「中文標頭 → 值」的物件，日期已轉成 `YYYY-MM-DD` 字串。存在 Supabase 的 `dataset_rows`，一個 Excel 列一筆；開啟儀表板時才分頁載入。                                              |
| 資料表     | `DataTable` / `table.key`        | 資料集裡一張可以拿來畫圖的表。以 Excel 表格物件名稱（`tbl_` 開頭）識別，活頁簿沒有表格物件時，改用工作表名稱。                                                                                         |
| 隱藏資料表 | `hidden: true`                   | 不出現在欄位清單裡的資料表。`使用說明`、`欄位定義`，以及沒有資料列的工作表（例如 `圖表預覽`）會自動隱藏，使用者可以手動取消。                                                                          |
| 欄位       | `Field`                          | 資料表裡的一欄。                                                                                                                                                                                       |
| 中文標頭   | `header`                         | 欄位在第 1 列的名稱，例如 `營業額`。**這是欄位的主要識別依據。**                                                                                                                                       |
| 欄位代碼   | `code`                           | `欄位定義` 工作表裡的英文代碼，例如 `revenue`。活頁簿沒有 `欄位定義` 時就沒有代碼。                                                                                                                    |
| 欄位參照   | `FieldRef` = `{ header, code? }` | 設定 JSON 裡指向某個欄位的寫法。比對時先比標頭，再比代碼，見 [ADR 0003](docs/adr/0003-field-identity-and-rebinding.md)。                                                                               |
| 欄位定義   | `dataDictionary`                 | 活頁簿裡名叫「欄位定義」的工作表，提供每個欄位的代碼、型別、單位。**這張表可有可無**，沒有的話系統就從資料推斷。                                                                                       |
| 資料型別   | `dataType`                       | `text` / `integer` / `number` / `percent` / `date`，對應 `欄位定義` 的 文字 / 整數 / 數值 / 百分比 / 日期。                                                                                            |
| 角色       | `role`                           | 欄位在圖表上怎麼用：**維度**（`dimension`，分類用，例如區域、年月）或**量值**（`measure`，數值，會被彙總，例如營業額）。資料型別不等於角色，例如 `月` 是整數，但角色是維度。                           |
| 比率欄位   | `ratio: true`                    | 由除法算出來的量值，例如營業利益率、平均客單價、日均來客數。**不可以加總，直接取平均也是錯的（非加權）。** 見 [ADR 0004](docs/adr/0004-field-roles-and-aggregation.md)。                               |
| 欄位類別   | `FieldKind`                      | 推薦圖表時對欄位的細分：**時間**（序列／週期）、**分類**、**識別**、**可加總量值**、**比率**。從中繼資料與資料列即時算出，不存進設定，見 [ADR 0010](docs/adr/0010-chart-recommendation-rules.md)。     |
| 級別       | `level`                          | 分類欄位依不同值的數量分成 少（2–6）、中（7–12）、多（13–30）、很多（31 以上），決定適合的圖表。                                                                                                       |
| 推測比率   | `inferred`                       | 沒被標成比率、但標頭像比率（結尾是 率、比、指數、均，或含「平均」「每」）的量值。推薦與預設彙總當成比率處理，欄位健檢會提醒使用者正式標記。                                                            |
| 資料表種類 | `TableKind`                      | 明細、彙總、主檔、參數、未分類。依表格名稱前綴判斷，沒有前綴時用推測。                                                                                                                                 |
| 一列代表   | `grain`                          | 在每一列都不重複的最小欄位組合，例如「門市名稱 × 年月」。                                                                                                                                              |
| 加權比率   | `ratioOf`                        | 知道分子、分母是哪兩欄的比率欄位，分組時算「分子加總 ÷ 分母加總」，數字是對的。從 Excel 公式 `分子/分母` 自動認出，也可以手動指定，見 [ADR 0008](docs/adr/0008-dashboard-filters-weighted-ratios.md)。 |
| 使用者覆寫 | `userOverride`                   | 使用者手動改過的角色、比率標記或分子分母。覆寫記在資料集上，切換資料來源時會沿用。                                                                                                                     |
| 彙總       | `agg`                            | 把多列合併成一個數字的方式：`sum` / `avg` / `count` / `min` / `max`。                                                                                                                                  |

## 儀表板端

| 名詞                  | 程式碼命名               | 定義                                                                                                                                                                                                                          |
| --------------------- | ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 儀表板                | `Dashboard`              | 一組 widget 加上版面，指向**一個**資料集。使用者可以建立多個。UI 上一律寫「儀表板」。                                                                                                                                         |
| Widget                | `Widget`                 | 儀表板上的一個元件：圖表、資料表格、KPI 卡或文字。每個 widget 只綁定一張資料表（文字元件不綁）。                                                                                                                              |
| 圖表類型              | `type`                   | `line` 折線、`bar` 長條、`combo` 組合、`pie` 圓餅、`scatter` 散佈、`radar` 雷達、`gauge` 儀表圖、`kpi` KPI 卡、`table` 資料表格、`text` 文字。                                                                                |
| 說明                  | `description`            | 顯示在 widget 標題下方的文字，用來寫計算口徑，例如「業績預估 ÷ 業績目標」。                                                                                                                                                   |
| 文字元件              | `text` / `content`       | 只放文字的 widget，用於區塊說明和指標定義，不綁資料表、沒有槽位。                                                                                                                                                             |
| 儀表圖                | `gauge`                  | 顯示單一數值落在範圍中哪個位置的圖。**UI 上一律寫「儀表圖」，不要只寫「儀表」**，以免和「儀表板」混淆。                                                                                                                       |
| 組合圖                | `combo`                  | 長條和折線疊在同一張圖上，可以分左右兩條 Y 軸，例如營業額用長條、營業利益率用折線。                                                                                                                                           |
| 選項                  | `options`                | 同一種圖表類型的變化型，例如 `area`、`stacked`、`horizontal`、`donut`，以及排序、前 N 名、門檻、合計。換選項不需要重新拖欄位。                                                                                                |
| 門檻                  | `thresholds`             | 依數值上色的兩個分界：低於 `warning` 紅、到 `success` 之前黃、達到 `success` 綠。用在長條圖、KPI 卡和表格的比率欄位。                                                                                                         |
| 槽位                  | `encoding.<slot>`        | widget 上可以放欄位的位置，例如 `x`、`y`、`group`。各圖表類型有哪些槽位，見 [ADR 0005](docs/adr/0005-dashboard-config-schema-v1.md)。                                                                                         |
| 明細槽位              | `encoding.detail`        | 散佈圖專用。決定「一個點代表什麼」，例如放門市代號就是一家店一個點；沒放的話，Excel 的每一列就是一個點。                                                                                                                      |
| 趨勢槽位              | `encoding.trend`         | KPI 卡專用。放時間類的維度欄位後，大數字下方會顯示迷你走勢圖。                                                                                                                                                                |
| 篩選                  | `filters[]`              | widget 層級的資料篩選，可同時設定多個欄位、每個欄位多選值；沒選任何值等於不篩選。有兩個入口，改的是同一份設定：編輯模式的「篩選」槽位，以及每張圖右上角的漏斗按鈕。                                                           |
| 儀表板篩選            | `Dashboard.filters`      | 格線上方的篩選列，套用到所有「資料表裡有這個欄位」的 widget。儀表板只記錄用哪些欄位；選了哪些值只在當次瀏覽有效（`uiStore.filterValues`），見 [ADR 0008](docs/adr/0008-dashboard-filters-weighted-ratios.md)。                |
| 推薦                  | `recommend`              | 依勾選的欄位組合，從 ADR 0010 的組合對照表列出 1～4 個候選元件（最後一個一律是表格），點選後新增元件。一鍵產生建議儀表板也用同一套規則。                                                                                      |
| 警告                  | `warnings`               | 元件設定違反對照表條件或通用檢查時的提醒，例如圓餅超過 6 類、比率被加總。只提醒、不阻止存檔，只在編輯模式顯示。                                                                                                               |
| 版面                  | `layout`                 | 每個 widget 在格線上的位置與大小 `{ i, x, y, w, h }`，格式就是 react-grid-layout 的原生格式。只存一份 12 欄的桌機版面；格線不到 900px 時自動重排成兩欄或一欄，不另外儲存，見 [ADR 0009](docs/adr/0009-responsive-layout.md)。 |
| 編輯模式 / 檢視模式   | `mode: 'edit' \| 'view'` | 編輯模式會顯示欄位清單和槽位，widget 可以拖動、縮放；檢視模式只顯示乾淨的儀表板，用於展示。編輯模式只在寬度 1200px 以上可用。                                                                                                 |
| 切換資料來源          | `rebind`                 | 把儀表板改成指向另一個資料集，例如換成下個月的報表，並依欄位參照重新對應欄位。                                                                                                                                                |
| 未儲存的變更          | `draftBase`              | 開啟中的儀表板有修改、還沒按「儲存」。修改包括版面、widget、名稱、篩選和切換資料來源，先只存在記憶體；`draftBase` 是最後一次儲存的版本，捨棄時還原成它。離開前會先詢問。                                                      |
| 欄位遺失              | `missingFields`          | 切換資料來源後對不上的欄位參照。受影響的 widget 會標示出來，讓使用者重新指定欄位。                                                                                                                                            |
| 欄位簽章              | `signature`              | 匯出儀表板時附帶的「用到哪些資料表、哪些欄位」清單。在別台電腦匯入時，用它檢查新上傳的活頁簿欄位是否齊全。                                                                                                                    |
| 範例資料 / 範例儀表板 | `sample`                 | `public/samples/` 裡的範例活頁簿，以及預先做好的範例儀表板，在首頁一鍵就能載入。                                                                                                                                              |

## 帳號與儲存

| 名詞     | 程式碼命名                          | 定義                                                                                                                                                            |
| -------- | ----------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 使用者   | `AuthUser` / `auth.uid()`           | 用 email 登入連結登入的人。沒有密碼，也沒有角色或權限等級之分。                                                                                                 |
| 登入連結 | magic link                          | 寄到使用者信箱、點了就登入的連結，只能用一次，過期要重新寄送。                                                                                                  |
| 擁有者   | `user_id`                           | 資料集、資料列、原始檔、儀表板都屬於建立它的使用者。資料庫用 RLS 限制**只能存取自己的資料**，所以沒有「分享」或「共用資料集」。                                 |
| 上傳狀態 | `status: 'uploading' \| 'ready'`    | 資料集寫進資料庫的進度。資料列分批寫入期間是 `uploading`，全部完成才是 `ready`；清單只顯示 `ready`。上傳失敗會整個刪掉，中斷超過 1 小時的會在下次登入時清掉。   |
| 原始檔   | `source-files` bucket               | 上傳時保存的那份活頁簿，路徑是 `<user_id>/<dataset_id>.xlsx`。資料集是解析後的結果，原始檔是解析前的檔案本身，刪除資料集時一起刪除。                            |
| 格式版本 | `SCHEMA_VERSION` / `schema_version` | 資料集和儀表板設定的格式版號，每筆記錄各自帶一個。讀到舊版本時由 `utils/schema.ts` 轉成目前的格式，見 [ADR 0005](docs/adr/0005-dashboard-config-schema-v1.md)。 |

## 關係

```
User 1 ─┬─ N Dataset 1 ─┬─ N DataTable 1 ─── N Field
        │       ▲       ├─ N Row（dataset_rows，以 table.key 分表）
        │       │       └─ 1 原始檔（source-files）
        │       │ N:1（datasetId，資料集刪除後儀表板保留）
        └─ N Dashboard 1 ─── N Widget ──→ 1 DataTable（table.key）
                               │
                               └─ encoding / filters ──→ FieldRef { header, code? }
```
