# CONTEXT：個人化儀表板 POC 名詞表

使用者在瀏覽器上傳**制式化 Excel**，把欄位拖進圖表的**槽位**，自己組出一個可以拖動、縮放的**儀表板**。整個系統只有前端，設定以 JSON 存在 localStorage，資料存在 IndexedDB。

這份文件定義專案裡的共用名詞。寫程式、寫文件、開 issue 時都用這裡的詞，程式碼裡則用「程式碼命名」欄的英文名稱。決策的理由記在 [`docs/adr/`](docs/adr/)。

## 資料端

| 名詞       | 程式碼命名                       | 定義                                                                                                                                                                         |
| ---------- | -------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 活頁簿     | `Workbook`                       | 使用者上傳的 `.xlsx` 檔案本身。                                                                                                                                              |
| 結構規範   | —                                | 可以上傳的 Excel 必須遵守的規則：第 1 列是標頭、第 2 列起是資料、沒有合併儲存格、沒有小計列。原文寫在範例檔的「使用說明」工作表。                                            |
| 工作表     | `sheetName`                      | Excel 裡的實體分頁。**只用來指 Excel 的分頁**，系統內「可以畫圖的一張表」請叫「資料表」。                                                                                    |
| 資料集     | `Dataset` / `datasetId`          | 一份活頁簿上傳、解析之後的結果。中繼資料（有哪些資料表、欄位、角色）存在 localStorage，資料列存在 IndexedDB。每上傳一次就產生一個新的資料集。                                |
| 資料表     | `DataTable` / `table.key`        | 資料集裡一張可以拿來畫圖的表。以 Excel 表格物件名稱（`tbl_` 開頭）識別，活頁簿沒有表格物件時，改用工作表名稱。                                                               |
| 隱藏資料表 | `hidden: true`                   | 不出現在欄位清單裡的資料表。`使用說明`、`欄位定義`，以及沒有資料列的工作表（例如 `圖表預覽`）會自動隱藏，使用者可以手動取消。                                                |
| 欄位       | `Field`                          | 資料表裡的一欄。                                                                                                                                                             |
| 中文標頭   | `header`                         | 欄位在第 1 列的名稱，例如 `營業額`。**這是欄位的主要識別依據。**                                                                                                             |
| 欄位代碼   | `code`                           | `欄位定義` 工作表裡的英文代碼，例如 `revenue`。活頁簿沒有 `欄位定義` 時就沒有代碼。                                                                                          |
| 欄位參照   | `FieldRef` = `{ header, code? }` | 設定 JSON 裡指向某個欄位的寫法。比對時先比標頭，再比代碼，見 [ADR 0003](docs/adr/0003-field-identity-and-rebinding.md)。                                                     |
| 欄位定義   | `dataDictionary`                 | 活頁簿裡名叫「欄位定義」的工作表，提供每個欄位的代碼、型別、單位。**這張表可有可無**，沒有的話系統就從資料推斷。                                                             |
| 資料型別   | `dataType`                       | `text` / `integer` / `number` / `percent` / `date`，對應 `欄位定義` 的 文字 / 整數 / 數值 / 百分比 / 日期。                                                                  |
| 角色       | `role`                           | 欄位在圖表上怎麼用：**維度**（`dimension`，分類用，例如區域、年月）或**量值**（`measure`，數值，會被彙總，例如營業額）。資料型別不等於角色，例如 `月` 是整數，但角色是維度。 |
| 比率欄位   | `ratio: true`                    | 由除法算出來的量值，例如營業利益率、平均客單價、日均來客數。**不可以加總，直接取平均也是錯的（非加權）。** 見 [ADR 0004](docs/adr/0004-field-roles-and-aggregation.md)。     |
| 使用者覆寫 | `userOverride`                   | 使用者手動改過的角色或比率標記。覆寫記在資料集上，切換資料來源時會沿用。                                                                                                     |
| 彙總       | `agg`                            | 把多列合併成一個數字的方式：`sum` / `avg` / `count` / `min` / `max`。                                                                                                        |

## 儀表板端

| 名詞                  | 程式碼命名               | 定義                                                                                                                                  |
| --------------------- | ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------- |
| 儀表板                | `Dashboard`              | 一組 widget 加上版面，指向**一個**資料集。使用者可以建立多個。UI 上一律寫「儀表板」。                                                 |
| Widget                | `Widget`                 | 儀表板上的一個元件：圖表、資料表格或 KPI 卡。每個 widget 只綁定一張資料表。                                                           |
| 圖表類型              | `type`                   | `line` 折線、`bar` 長條、`combo` 組合、`pie` 圓餅、`scatter` 散佈、`radar` 雷達、`gauge` 儀表圖、`kpi` KPI 卡、`table` 資料表格。     |
| 儀表圖                | `gauge`                  | 顯示單一數值落在範圍中哪個位置的圖。**UI 上一律寫「儀表圖」，不要只寫「儀表」**，以免和「儀表板」混淆。                               |
| 組合圖                | `combo`                  | 長條和折線疊在同一張圖上，可以分左右兩條 Y 軸，例如營業額用長條、營業利益率用折線。                                                   |
| 選項                  | `options`                | 同一種圖表類型的變化型，例如 `area`、`stacked`、`horizontal`、`donut`。換選項不需要重新拖欄位。                                       |
| 槽位                  | `encoding.<slot>`        | widget 上可以放欄位的位置，例如 `x`、`y`、`group`。各圖表類型有哪些槽位，見 [ADR 0005](docs/adr/0005-dashboard-config-schema-v1.md)。 |
| 明細槽位              | `encoding.detail`        | 散佈圖專用。決定「一個點代表什麼」，例如放門市代號就是一家店一個點；沒放的話，Excel 的每一列就是一個點。                              |
| 趨勢槽位              | `encoding.trend`         | KPI 卡專用。放時間類的維度欄位後，大數字下方會顯示迷你走勢圖。                                                                        |
| 篩選                  | `filters[]`              | widget 層級的資料篩選。v1 沒有整個儀表板共用的全域篩選。                                                                              |
| 版面                  | `layout`                 | 每個 widget 在格線上的位置與大小 `{ i, x, y, w, h }`，格式就是 react-grid-layout 的原生格式。                                         |
| 編輯模式 / 檢視模式   | `mode: 'edit' \| 'view'` | 編輯模式會顯示欄位清單和槽位，widget 可以拖動、縮放；檢視模式只顯示乾淨的儀表板，用於展示。                                           |
| 切換資料來源          | `rebind`                 | 把儀表板改成指向另一個資料集，例如換成下個月的報表，並依欄位參照重新對應欄位。                                                        |
| 欄位遺失              | `missingFields`          | 切換資料來源後對不上的欄位參照。受影響的 widget 會標示出來，讓使用者重新指定欄位。                                                    |
| 欄位簽章              | `signature`              | 匯出儀表板時附帶的「用到哪些資料表、哪些欄位」清單。在別台電腦匯入時，用它檢查新上傳的活頁簿欄位是否齊全。                            |
| 範例資料 / 範例儀表板 | `sample`                 | `public/samples/` 裡的範例活頁簿，以及預先做好的範例儀表板，在首頁一鍵就能載入。                                                      |

## 關係

```
Dataset 1 ─── N DataTable 1 ─── N Field
   ▲
   │ N:1（datasetId）
Dashboard 1 ─── N Widget ──→ 1 DataTable（table.key）
                  │
                  └─ encoding / filters ──→ FieldRef { header, code? }
```
